# Hugo Site Source Directory

이 디렉터리는 김규진 개인 포트폴리오 웹사이트의 Hugo 정적 사이트 소스 루트 폴더입니다.

- `config/_default/`: Hugo 전역 환경설정 (hugo.toml, params.toml, menu.toml 등)
- `content/`: 포트폴리오 페이지(소개, 링크, 아카이브, 검색) 및 대표 프로젝트 포스트 마크다운
- `assets/`: 커스텀 SCSS 스타일시트(`scss/custom.scss`) 및 프로필 아바타 이미지
- `themes/template/`: Hugo Theme Stack 기반 템플릿 레이아웃
